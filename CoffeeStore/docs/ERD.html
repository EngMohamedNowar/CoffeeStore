3) CoffeeStoreDb.Identity — المستخدمين · الأدوار · عناوين المستخدم

كيان UserAddress (الجدول Addresses) هو بيزنس «اليوزر ليه أكتر من عنوان» — وفيه IsDefault اللي بيمثّل عنوان التوصيل المفضّل. جداول AspNetUserClaims / Logins / Tokens / RoleClaims متـ Ignore وموجودة في القاعدة.

    USER {

        string UserId PK_FK

ملاحظة: جدول Addresses ده تابع لقاعدة الهوية، ومش هو جدول Customers.Addresses القديم — ده كان في قاعدة المتجر واتشال من الكود. عنوان التوصيل النهائي بينحفظ كـ snapshot مجمّد داخل Orders.ShipToAddress_*.

5) ليجند العلاقات — ليه كل FK عامل كده؟

RelationshipFKOn Deleteالسبب
Category → CategoryParentCategoryId Restrict شجرة تصنيفات — مينفعش تحذف أب وهو عنده أبناء
Category → ProductProducts.CategoryId Restrict متحذفش تصنيف جواه منتجات
Product → ProductVariantProductVariants.ProductId Cascade حذف المنتج يمسح أوزانه وطحناته معاه
Customer → CartCarts.CustomerId (unique) Cascade سلة واحدة نشطة لكل عميل
Cart → CartItemCartItems.CartId Cascade حذف السلة يمسح محتوياتها
ProductVariant → CartItemCartItems.ProductVariantId Restrict متحذش variant وهو في سلة حد
Customer → OrderOrders.CustomerId Restrict حماية سجل الطلبات لو بيانات العميل اتمسحت
DeliveryMethod → OrderOrders.DeliveryMethodId Restrict متحذفش طريقة توصيل متسجّل بيها أوردرات
Order → OrderItemOrderItems.OrderId Cascade حذف الأوردر يمسح بنوده
ProductVariant → OrderItemOrderItems.ProductVariantId Restrict مرجع تاريخي + الاسم والسعر محفوظين كـ snapshot
Order → PaymentPayments.OrderId (unique) Cascade دفع واحد لكل أوردر (1:1)
User → UserAddressAddresses.UserId Cascade عنوان المستخدم يروح معاه
علاقة منطقية (بدون FK)السبب
Customer.IdentityUserId → Users.Id cross-DB القاعدتين مختلفتين فمفيش FK — الربط بـ unique index
Order.UserEmail → Users.Email soft link نص حر للتفريق بين المستخدمين
BasketItem.ProductId → ProductVariant Redis السلة في Redis ومبيتحمّلش من القاعدة
ملاحظات على التصميم
Soft delete IsDeleted + query filter على أغلب الجداول (ماعدا OrderItems)
Owned types ShipToAddress و ItemOrdered أعمدتهم على نفس الجدول — قيمة مجمّدة مش جدول مستقل
عمود ميّت Orders.ShippingAddressId مفيش عليه FK ولا index ولا استخدام
Identity extras UserClaims / UserLogins / UserTokens / RoleClaims متـ Ignore — مش موجودة
